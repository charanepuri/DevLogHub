# DevLog Hub | Charan Teja's Engineering & Learning Portfolio 🚀

## 🌟 Overview

**DevLog Hub** is a lightweight, responsive single-page application built strictly with **pure semantic HTML5, internal CSS3, and internal vanilla JavaScript**. Zero npm dependencies, zero CSS frameworks, and zero build tools are required.

The application indexes and visualizes technical posts authored by **Charan Teja** on LinkedIn, alongside links to his live frameworks, project hubs, and social profiles.

## ⚡ Features

- **100% Pure HTML5, Internal CSS & Vanilla JS**: Single portable file (`index.html`) that works right away in any browser without local server setups.
- **Dedicated Documentation Showcase**: In-depth architecture guides, JavaScript engine internals, and visual infographics are cleanly isolated into their own dedicated `Technical Docs` track.
- **Interactive Portfolios & Social Ecosystem**: Direct showcase of all live framework portfolios (React, Django, Flask, Angular), dedicated GitHub project hubs, and verified social profiles.
- **Instant Search**: Real-time live filtering by keyword, day number (e.g. `Day 10`), concept name (e.g. `DOM`, `Event Loop`, `JOIN`, `Multithreading`, `JWT`, `LLM`, `ORM`, `AI Agents`), or topic description.
- **Track Filtering**: Fast switching between all categories with live milestone counts.
- **Sorting Options**: View posts by roadmap sequence or sort alphabetically (A-Z, Z-A).
- **Dark / Light Mode**: Seamless theme switcher preserving user preference in `localStorage`.
- **Direct LinkedIn Links**: Each card features a direct button to read the full original post on LinkedIn.
- **One-Click Link Copying**: Copy any post's direct LinkedIn link straight to the clipboard with animated toast feedback.

## 🚀 How to Run Locally

### Option 1: Direct File Opening (Simplest)

Double-click `index.html` or drag and drop it into any modern web browser (Chrome, Edge, Firefox, Safari, Brave).

### Option 2: Local HTTP Server (Optional)

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

Then open: `http://localhost:8000`

---

## 🛠️ Re-generating or Updating Links

If you update links in any of the raw text files, recompile the website with:

```powershell
python compile_all_sources.py
python generate_site.py
```
